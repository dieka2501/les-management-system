Instruksi Pengujian Instagram App

Halaman ini menjelaskan alur dasar untuk reviewer atau tester saat mengecek integrasi chatbot Instagram Rumah Privat Madani.

Website URL

Gunakan homepage domain deployment sebagai URL Situs. Pada development lokal, jalankan server lalu buka tunnel HTTPS publik sebelum memasukkan URL ke Meta.

Alur pengujian chatbot

  1. Buka halaman simulator provider di /provider/chat-simulations.
  2. Masukkan password test yang diberikan di catatan review Meta App. Tidak ada username.
  3. Pilih mode Gemini AI untuk menguji jawaban berbasis AI dan knowledge base.
  4. Kirim pertanyaan seputar paket les, harga, area layanan, materi belajar, atau pendaftaran.
  5. Untuk menguji handoff, kirim pesan seperti Saya mau daftar les, lalu jawab setuju saat chatbot meminta konfirmasi.

Alur pengujian Instagram DM

  1. Kirim DM ke akun Instagram Professional Rumah Privat Madani yang terhubung ke Meta App.
  2. Gunakan pesan uji seperti Ada paket apa saja? atau Area layanannya di mana?.
  3. Chatbot akan menjawab hanya berdasarkan knowledge base Rumah Privat Madani.
  4. Jika percakapan sudah diteruskan ke admin, chatbot tidak membalas lagi agar admin manusia bisa mengambil alih.
Jangan menaruh password test publik di halaman ini. Masukkan password hanya di field instruksi review Meta App.
