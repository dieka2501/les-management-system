Penghapusan Data Pengguna

Instruksi Penghapusan Data

Pengguna dapat meminta penghapusan data yang terkait dengan interaksi chatbot Rumah Privat Madani, termasuk riwayat pesan, metadata sesi, dan informasi yang diberikan secara sukarela.

Cara mengajukan permintaan

  1. Kirim email ke dieka.koes@gmail.com dengan subjek Permintaan Penghapusan Data Chatbot.
  2. Sertakan nama, platform yang digunakan, misalnya Instagram DM atau website, dan perkiraan tanggal percakapan.
  3. Jika permintaan terkait Instagram, sertakan username Instagram yang dipakai untuk menghubungi akun Rumah Privat Madani.
  4. Admin akan melakukan verifikasi kepemilikan akun atau kecocokan data sebelum penghapusan diproses.

Alternatif WhatsApp

Pengguna juga dapat menghubungi WhatsApp 0812 8367 9665 dan menyebutkan bahwa permintaan berkaitan dengan penghapusan data chatbot.

Waktu pemrosesan

Permintaan akan diproses setelah verifikasi selesai. Jika ada data yang wajib disimpan untuk kebutuhan administratif, keamanan, atau kepatuhan, Rumah Privat Madani dapat menyimpan data terbatas sesuai kebutuhan tersebut.

Untuk Meta App Dashboard: gunakan URL halaman ini sebagai URL Petunjuk Penghapusan Data.
