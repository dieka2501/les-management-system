Kebijakan Privasi

Kebijakan ini menjelaskan bagaimana Rumah Privat Madani memproses data saat pengguna berinteraksi dengan chatbot informasi melalui website, simulator, atau Instagram DM.

Data yang dapat diproses

  • Pesan yang dikirim pengguna ke chatbot.
  • ID akun atau metadata teknis yang dikirim oleh platform, misalnya Instagram sender ID.
  • Informasi yang pengguna berikan secara sukarela, seperti nama anak, kelas, domisili, kebutuhan belajar, atau preferensi jadwal.
  • Catatan sesi percakapan untuk evaluasi kualitas respons dan handoff ke admin.

Tujuan penggunaan data

  • Menjawab pertanyaan seputar layanan Rumah Privat Madani berdasarkan knowledge base.
  • Menghubungkan percakapan ke admin manusia jika pengguna menyetujui handoff.
  • Meningkatkan akurasi knowledge base dan kualitas layanan pelanggan.
  • Menjaga keamanan, mencegah penyalahgunaan, dan memenuhi kebutuhan operasional.

Pembatasan penggunaan

Rumah Privat Madani tidak menjual data pribadi pengguna. Chatbot tidak digunakan untuk membuat keputusan otomatis yang berdampak hukum terhadap pengguna. Informasi yang belum tersedia di knowledge base akan diarahkan untuk dikonfirmasi oleh admin.

Penyimpanan dan keamanan

Data percakapan disimpan sepanjang dibutuhkan untuk operasional, evaluasi layanan, atau kewajiban administratif. Akses ke dashboard pengujian chatbot dilindungi password dan session cookie. Secret seperti API key dan access token disimpan di environment server, bukan di source code publik.

Penghapusan data

Pengguna dapat meminta penghapusan data melalui halaman Instruksi Penghapusan Data. Permintaan akan diproses setelah identitas atau kepemilikan akun dapat diverifikasi secara wajar.
